# A-share ETF PCF Metrics

Deterministic scripts and a Codex/Claude skill for A-share listed ETF PCF look-through metrics.

The workflow reads exchange PCF creation/redemption baskets, looks through full underlying holdings, and calculates dividend yield, PE, PB, return, volatility, Sortino, drawdown, overlap, exposure, and constraint metrics.

## Workflows

### Batch HK ETF ranking

```powershell
# Run this from the repository or installed skill directory.
$SKILL_DIR = Resolve-Path .
python "$SKILL_DIR\scripts\run_pcf_metrics.py" --etf 513690,159569 --out-dir pcf-metrics-output
```

Final outputs:

- `pcf_full_metrics_table.csv`
- `pcf_full_metrics_table.xlsx`

Use a CSV list:

```powershell
python "$SKILL_DIR\scripts\run_pcf_metrics.py" --input ".\my_etf_list.csv" --code-column "ETF代码"
```

The default input path is `lookthrough-hk-all-ranking/all_etf_summary.csv`. It is not bundled and must be generated by the earlier ETF discovery workflow, or replaced by explicit `--etf` codes.

### Selected ETF or ETF portfolio

```powershell
python "$SKILL_DIR\scripts\selected_etf_lookthrough.py" --etf 159569,159758 --weights 60,40 --out-dir selected-etf-output
```

Outputs:

- `metrics_summary.csv`
- `lookthrough_summary.csv`
- `lookthrough_detail.csv`
- `etf_summary.csv`
- `lookthrough_report.xlsx`
- Enhanced audit files: `classified_detail.csv`, `structure_analysis.csv`, `market_board_exposure.csv`, `industry_theme_exposure.csv`, `valuation_buckets.csv`, `profit_quality.csv`, `dividend_quality.csv`, `risk_analysis.csv`, `overlap_pairs.csv`, `common_holdings.csv`, `pcf_quality.csv`, `cross_validation.csv`, `constraint_checks.csv`, `historical_tracking.csv`
- Reports and reproducibility files: `enhanced_report.md`, `enhanced_report.html`, `run_summary.json`, `run_manifest.json`, and optional `cache/holdings_*.csv`

The `PORTFOLIO` row recomputes valuation metrics from underlying stock weights. Portfolio return, volatility, Sortino, drawdown, Sharpe, Calmar, VaR/CVaR, and downside volatility are calculated from the combined ETF NAV/price curve when enough ETF history is available.

Useful options:

```powershell
python "$SKILL_DIR\scripts\selected_etf_lookthrough.py" --etf 159569,159758 --weights 60,40 --max-stock-weight 7 --max-industry-weight 30 --min-dividend-yield 3 --refresh-cache
```

The selected workflow accepts `--compare`, `--portfolio`, `--industry`, `--theme`, `--risk`, and `--html-report`; those enhanced outputs are generated by default. Cache snapshots are on by default and can be disabled with `--no-cache`.

## Metric Method

- Dividend yield: weighted look-through constituent dividend yield.
- PE: earnings-yield aggregation.
- PB: weighted PB over covered positive PB constituents.
- Return/risk: ETF NAV or price history. Short ETF history stays blank and records source diagnostics in `收益错误`.
- Concentration: top 5/10/20 and max-stock exposure are calculated after merging duplicated stocks across ETFs.
- Industry/theme: currently rule-based estimates, explicitly marked as non-official SW/CITIC mapping.
- Three-year return remains blank when history is too short.

## Installation

```powershell
python -m pip install -r requirements.txt
```

Network access is required for exchange PCF files, stock valuation/dividend data, HK spot prices, HKD/CNY FX quotes, and ETF return histories.

## Validation

## Notes

- `run_pcf_metrics.py` deletes intermediate files unless `--keep-intermediates` is set.
- `selected_etf_lookthrough.py` keeps detailed audit files by design.
- Generated outputs are ignored by `.gitignore` to avoid accidental commits.
