# A-share ETF PCF Metrics

Deterministic scripts and a Codex/Claude skill for A-share listed ETF PCF look-through metrics.

The workflow reads SSE/SZSE PCF creation/redemption baskets, looks through full underlying holdings, and calculates dividend yield, PE, PB, return, volatility, Sortino, drawdown, overlap, exposure, and constraint metrics. It supports A-share, Hong Kong, and US-stock underlyings when those assets are exposed in exchange PCF files.

## Workflows

### Batch HK ETF ranking

```powershell
$SKILL_DIR = Resolve-Path .
python "$SKILL_DIR\scripts\run_pcf_metrics.py" --etf 513690,159569 --out-dir pcf-metrics-output
```

Final outputs:

- `pcf_full_metrics_table.csv`
- `pcf_full_metrics_table.xlsx`

Use a CSV list:

```powershell
python "$SKILL_DIR\scripts\run_pcf_metrics.py" --input ".\my_etf_list.csv" --code-column "ETF代码"
```

The default input path is `lookthrough-hk-all-ranking/all_etf_summary.csv`. It is not bundled and must be generated by the earlier ETF discovery workflow, or replaced by explicit `--etf` codes.

### Batch US ETF ranking

```powershell
python "$SKILL_DIR\scripts\run_pcf_metrics.py" --market us --etf 513100,513500 --out-dir lookthrough-us-pcf-risk
```

US mode reuses the selected ETF engine internally and extracts ETF rows into the same final output names. Use `--keep-intermediates` to retain `lookthrough_detail.csv`, `metrics_summary.csv`, and diagnostics.

### US-listed ETF ticker look-through

Use this path when the ETF itself is listed in the US, for example `QQQ.US` or `DRAM.US`. Do not pass these tickers to `selected_etf_lookthrough.py --etf`, because that command expects A-share listed six-digit ETF codes.

```powershell
python "$SKILL_DIR\scripts\us_listed_etf_lookthrough.py" --ticker QQQ.US --out-dir us-etf-output
python "$SKILL_DIR\scripts\us_listed_etf_lookthrough.py" --ticker QQQ.US,DRAM.US --weights 50,50 --out-dir us-etf-portfolio-output
python "$SKILL_DIR\scripts\us_listed_etf_lookthrough.py" --ticker QQQ.US --skip-metrics --out-dir us-qqq-holdings
python "$SKILL_DIR\scripts\us_listed_etf_lookthrough.py" --ticker QQQ.US,DRAM.US --full-output --out-dir us-etf-full-audit
```

The direct US-listed workflow writes a compact default output:

- `lookthrough_detail.csv`
- `lookthrough_summary.csv`
- `etf_summary.csv`
- `metrics_summary.csv`
- `lookthrough_report.xlsx`
- `run_manifest.json`

Use `--full-output` only when you need auxiliary CSV, Markdown, HTML, and extra audit files.

Current source behavior:

- US-listed ETF ticker resolution first uses the SEC mutual fund/class ticker map (`company_tickers_mf.json`), then the SEC exchange ticker map, so it is not limited to hand-coded NYSE Arca/Nasdaq/Cboe examples.
- SEC NPORT fallback provides full holdings when available; NPORT is complete but delayed.
- Roundhill ETFs such as `DRAM` use the issuer daily holdings CSV when available.
- `QQQ` can use SEC NPORT as a full-holdings fallback when the Invesco API rejects script requests.
- Constituent PE/PB, price, and dividend yield use Yahoo quoteSummary with crumb authentication when available.
- Sector and industry use Nasdaq quote endpoints when available.
- ETF return/risk metrics use Nasdaq chart data when available and portfolio return/risk is recomputed from the combined ETF price curves.
- Default mode does not write cache files. Add `--cache` to store holdings, constituent metrics, and ETF price histories under `out-dir/cache`; use `--refresh-cache` to clear cache files before a cached run.
- `--lookback-days` is accepted as an alias for `--nav-lookback-days`.

- `--refresh-cache`: remove old `cache/holdings_*.csv` snapshots before a run.

## Metric Method

- Dividend yield: weighted look-through constituent dividend yield.
- PE: earnings-yield aggregation, `sum(weight) / sum(weight / PE)`.
- PB: weighted PB over covered positive PB constituents.
- Return/risk: ETF NAV or price history. Short ETF history stays blank and records source diagnostics in `收益错误`.
- Portfolio return/risk: calculated from the combined ETF NAV/price curve, not from weighted precomputed ETF metrics.
- Concentration: top 5/10/20 and max-stock exposure are calculated after merging duplicated stocks across ETFs.
- Industry/theme: currently rule-based estimates, explicitly marked as non-official SW/CITIC mapping.
- Three-year return remains blank when history is too short.
- US ticker normalization: strips whitespace, uppercases, and preserves letters, digits, dots, and hyphens; it does not zero-fill `AAPL`, `MSFT`, `NVDA`, `BRK.B`, or `BRK-B`.
- US PCF weights: prefer PCF cash substitute amount divided by `NAVperCU`. If only quantity is available, the helper may estimate with `ComponentShare * US latest price * USD/CNY / NAVperCU` and records that formula in the weight source.
- US valuation: best effort via existing AkShare endpoints for latest price, PE, PB, and dividend yield. Missing or rate-limited data is left blank with the error recorded in valuation diagnostics.
- US industry/board classification is not an official sector mapping; current enhanced outputs classify the board as `美股` and keep rule industry/theme as estimates.

## Notes

- `run_pcf_metrics.py` deletes intermediate files unless `--keep-intermediates` is set.
- `selected_etf_lookthrough.py` keeps detailed audit files by design.
- Generated outputs are ignored by `.gitignore` to avoid accidental commits.
- Cross-border PCF files can expose cash substitute rows, incomplete component metadata, or exchange-specific source codes. The scripts keep raw source codes and diagnostics instead of guessing silently.
- US market and valuation endpoints can be rate-limited or incomplete. Missing constituent metrics are recorded in `估值错误`; ETF-level PE/PB still aggregate from covered constituents when coverage is available.
- Outputs are data calculations, not investment advice.
