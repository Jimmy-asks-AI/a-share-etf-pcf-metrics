# Output Schema

All percentages are stored as percentage points. For example, `6.5` means `6.5%`, not `0.065`.

Blank values mean the source did not provide enough reliable data, or the metric was intentionally not computed because the coverage/window was insufficient.

## `pcf_full_metrics_table.csv`

Generated by `scripts/run_pcf_metrics.py`.

| Column | Unit | Meaning | Blank semantics |
|---|---:|---|---|
| `排名_按股息率` | rank | Dividend-yield descending rank. | Never blank when rows exist. |
| `ETF代码` | text | A-share listed ETF code, six digits. | Never blank. |
| `ETF名称` | text | ETF display name from source list or quote data. | May be blank if quote lookup fails. |
| `穿透口径` | text | `PCF申赎篮子估算`、基金季报、SEC N-PORT 或发行商持仓。 | 失败行可空。 |
| `持仓期` | text | PCF trading day or fallback holdings period. | Blank only if upstream summary is malformed. |
| `持仓来源` | text | `sse_pcf`, `szse_pcf`, `reported_holdings`, or mixed source labels. | Never blank for completed rows. |
| `港股持仓权重%` | % | Sum of HK stock weights found in the ETF basket. | Blank if HK holdings could not be measured. |
| `股息率%` | % | Weighted look-through dividend yield over covered holdings. | Blank if no constituent dividend yield coverage. |
| `股息率覆盖权重%` | % | Holding weight with a usable dividend yield. | Below 80 means the row does not receive an effective dividend rank by default. |
| `PE` | multiple | Earnings-yield aggregation PE: `sum(weight) / sum(weight / PE)`. Non-positive PE is excluded from denominator. | Blank if no positive PE coverage. |
| `PB` | multiple | Weighted PB over covered positive PB holdings. | Blank if no positive PB coverage. |
| `PB覆盖权重%` | % | Holding weight with valid positive PB. | `0` means no positive PB coverage. |
| `年化收益%` | % | ETF one-year annualized return from the selected NAV/price source. | Blank if return window is too short or unavailable. |
| `索提诺比率` | ratio | Daily-return Sortino ratio annualized with 252 trading days. | Blank if downside observations are insufficient. |
| `波动率%` | % | Annualized volatility from daily returns. | Blank if observations are insufficient. |
| `近半年收益%` | % | Trailing roughly 183-day total return. | Blank if window is too short. |
| `近一年收益%` | % | Trailing roughly 365-day total return. | Blank if window is too short. |
| `近3年收益%` | % | Trailing roughly three-year total return. | Blank if less than the minimum history window. |
| `收益来源` | text | Selected NAV/price source such as `eastmoney_nav`, `eastmoney_price`, or `sina_price`. | Blank if all sources failed. |
| `收益口径` | text | Total-return/adjusted or unadjusted price return. | Unadjusted price return excludes cash distributions. |
| `收益币种` | text | Return currency, normally CNY for selected cross-market portfolios and USD for standalone US-listed ETF runs. | Blank if returns failed. |
| `收益区间` | date range | First and last dates used for annualized return. | Blank if annualized return is unavailable. |
| `风险指标区间` | date range | First and last dates used for Sortino/volatility. | Blank if risk metrics unavailable. |
| `PE覆盖权重%` | % | Holding weight with valid positive PE. | `0` means no positive PE coverage. |
| `负PE权重%` | % | Holding weight with non-positive PE. | `0` means no reported non-positive PE. |
| `PCF原始股票行数`、`有效权重行数`、`未定价/缺失权重行数` | count | Raw, usable, and unresolved stock component counts. | Failure rows can be blank. |
| `数据状态`、`错误` | text | `有效`、`覆盖不足` or `失败`, plus diagnostics. | Never silently omit a requested ETF. |

## `metrics_summary.csv`

Generated by `scripts/selected_etf_lookthrough.py`.

Contains one row per ETF plus one `PORTFOLIO` row.

| Column | Unit | Meaning |
|---|---:|---|
| `类型` | text | `ETF` or `组合`. |
| `ETF代码` | text | ETF code, or `PORTFOLIO` for the combined row. |
| `ETF名称` | text | ETF display name, or comma-separated ETF codes for the portfolio row. |
| `ETF权重%` | % | User-supplied normalized ETF portfolio weight. |
| `穿透模式` | text | `hk`, `a`, `auto`, or portfolio look-through label. |
| `股票权重合计%` | % | Sum of stock weights used for metric aggregation. Can be slightly above/below 100 due to PCF cash and rounding. |
| `股息率%`, `PE`, `PB` | mixed | Look-through valuation metrics. Portfolio row is recomputed from underlying stock weights. |
| `年化收益%`, `索提诺比率`, `波动率%` | mixed | ETF or portfolio historical NAV/price metrics. Portfolio row uses the combined ETF curve. |
| `收益错误` | text | Serialized error details if return history failed. Blank means no return-source error was recorded. |
| `收益口径`, `收益币种`, `组合构造` | text | Adjusted/price-return basis, base currency, and buy-and-hold portfolio construction rule. |

## `lookthrough_summary.csv`

Aggregated underlying stock exposure for the selected ETF portfolio.

Key columns:

- `排名`: descending by `组合穿透权重%`.
- `底层市场`: `A` or `HK`.
- `股票代码`, `股票名称`: normalized constituent identity.
- `组合穿透权重%`: total portfolio weight in that stock.
- `覆盖ETF数`: number of ETFs in the portfolio containing the stock.
- `股票PE`, `股票PB`, `股票股息率%`: constituent-level metrics used for aggregation.

## `lookthrough_detail.csv`

Per-ETF constituent-level rows before aggregation. Use this file for audit trails and debugging.

Important columns:

- `ETF内权重%`: stock weight inside a single ETF PCF basket.
- `组合穿透权重%`: `ETF权重% * ETF内权重% / 100`.
- `权重来源`: PCF weight formula or price fallback method.
- `估值来源`, `股息率来源`, `估值错误`: source-level audit fields.

## Enhanced selected workflow outputs

Generated by `scripts/selected_etf_lookthrough.py` for every selected ETF or ETF portfolio run.

| File | Main content |
|---|---|
| `classified_detail.csv` | `lookthrough_detail.csv` plus board, rule-industry, theme, and data-source classification columns. |
| `structure_analysis.csv` | Holding count, effective holding count, stock-weight total, cash/other estimate, top 5/10/20 concentration, and max single-stock weight. Concentration and max stock are calculated after merging duplicated stock codes across ETFs. |
| `market_board_exposure.csv` | Exposure by market (`A`, `HK`, cash/other estimate) and A-share board (`主板`, `创业板`, `科创板`, etc.). |
| `industry_theme_exposure.csv` | Exposure by estimated SW level-1, estimated CITIC level-1, rule industry, and theme, with PE/PB/dividend-yield aggregates. Current SW/CITIC fields are explicit rule estimates, not official mappings. |
| `valuation_buckets.csv` | PE, PB, and dividend-yield bucket weights plus high-PE and non-positive-PE weights. |
| `profit_quality.csv` | Weighted implied ROE (`PB/PE`) plus placeholders for ROA, margins, growth, cash-flow quality, and R&D ratio when financial-statement sources are not connected. |
| `dividend_quality.csv` | Current weighted dividend yield, non-dividend weight, high-dividend weights above 3% and 5%, plus placeholders for multi-year dividend quality fields. |
| `risk_analysis.csv` | Annualized return, volatility, Sortino, max drawdown, Sharpe, Calmar, beta, VaR95, CVaR95, downside volatility, and diagnostics. Blank risk metrics mean ETF history was too short or all return sources failed. |
| `overlap_pairs.csv` | Pairwise ETF Jaccard similarity, weighted overlap, and common holding count. |
| `common_holdings.csv` | Stocks held by more than one ETF, with covered ETF count and combined look-through weight. |
| `pcf_quality.csv` | PCF date/source, stock-weight total, cash/other estimate, abnormal-weight hint, XML-candidate note, and PCF-vs-report placeholder. |
| `cross_validation.csv` | PE/PB/dividend coverage score, source-comparison placeholders, NAV-vs-price diagnostics, and anomaly hints. Coverage score is capped at 100 even when PCF stock weights sum above 100. |
| `constraint_checks.csv` | Checks configured by CLI options such as `--max-stock-weight`, `--max-industry-weight`, `--min-dividend-yield`, `--max-pe`, `--max-pb`, `--max-drawdown`, `--target-a-weight`, and `--target-hk-weight`. |
| `historical_tracking.csv` | Cache snapshot count, current snapshot path, estimated turnover when at least two cached snapshots exist, and placeholders for industry/valuation history. |
| `enhanced_report.md` / `enhanced_report.html` | Reader-friendly extracts of key enhanced tables. |
| `run_manifest.json` | Run id, timestamp, CLI args, output row counts, output columns, and reproducibility notes. |

## Cache semantics

The selected workflow does not cache by default. Use `--cache` to write `cache/holdings_<portfolio_signature>_<run_id>.csv`. Only snapshots with the same ETF/weight signature are compared. Use `--refresh-cache` to clear older generated holdings snapshots in the selected output directory.
